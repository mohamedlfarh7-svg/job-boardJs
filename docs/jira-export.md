## Definition of Done

Une User Story ou une tâche est considérée comme terminée lorsque :

- les critères d’acceptation sont respectés ;
- le travail est testé ;
- le code ou le livrable est propre et lisible ;
- les modifications sont versionnées avec Git ;
- le statut Jira est mis à jour ;
- le livrable est prêt pour la validation.
