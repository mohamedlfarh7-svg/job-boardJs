# Analyse du cahier des charges

## 1. Présentation du projet

Le projet consiste à créer un portail web interne de stages et
d'alternances permettant aux apprenants de consulter et gérer
des offres.

## 2. Objectifs

- Consulter les offres
- Rechercher une offre
- Filtrer les offres
- Consulter le détail d'une offre
- Suivre des offres
- Déposer une offre
- Administrer les offres

## 3. Utilisateurs

### Apprenant

- Consulter les offres
- Rechercher et filtrer
- Consulter les détails
- Suivre des offres

### Administrateur

- Créer une offre
- Modifier une offre
- Supprimer une offre
- Gérer les technologies

## 4. Pages principales

- Liste des offres
- Détail d'une offre
- Dépôt d'une offre
- Offres suivies
- Administration

## 5. Contraintes techniques

- HTML
- CSS
- Responsive design
- Git/GitHub

## 6. Hors périmètre

- Authentification
- Backend
- Base de données
- API REST
- Upload de fichiers
- Paiement
- Envoi réel d'emails
